# Show HN: DevPulse AI – Open-source dashboard to measure if AI coding tools actually deliver ROI

**Title:** Show HN: DevPulse AI – Measure if AI coding tools deliver ROI or cost you in rework

**URL:** https://github.com/TimurRakhmatullin86/devpulse-ai

**Text:**

CTO pays $19-100/dev/month for Copilot, Cursor, Claude Code. 100 devs = $24K-120K/year. CFO asks: "Is this worth it?" Nobody has a good answer.

AI-assisted PRs merge faster. But 2-3 weeks later — rework, incidents, churn. Traditional velocity metrics show growth while quality silently drops. I built DevPulse AI to measure both sides honestly.

**What it does:** Connects to GitHub repos via a GitHub App, detects AI-assisted PRs, and computes: AI Usage Rate, Cycle Time (AI vs non-AI), Rework Rate (fix PRs within 14d), Bug Rate, Code Churn, Review Load, and a Net Productivity Score that balances speed against quality.

**AI detection — honest about limitations:** It's marker-based, not AST analysis. Detects Co-Authored-By headers (Copilot, Claude, Cursor), commit message patterns ("Generated by", "[ai]"), PR body markers, AI config files (.cursor/, CLAUDE.md). There's an experimental heuristic (500+ lines in <30 min). If a dev removes the Co-Authored-By header, it's invisible. I'd rather under-count than over-count.

**Dashboard:** Executive summary (one ROI number), Speed vs Quality comparison, per-developer scatter plot, per-repo breakdown, 12-week trends, ROI calculator (input license costs + salaries, get dollar impact).

**Competitive context:** Exceeds AI raised $4.6M and charges $49/manager/month for this. Jellyfish, LinearB, GetDX do engineering analytics but can't attribute code to AI. GitHub's Copilot Metrics Viewer is Copilot-only. DevPulse AI is open-source, self-hosted, free.

Tech: Next.js 14, Tailwind, Recharts, PostgreSQL, Prisma, NextAuth (GitHub OAuth), Octokit. Docker Compose or Vercel deploy.

MIT license. Looking for feedback on the detection heuristics especially.
