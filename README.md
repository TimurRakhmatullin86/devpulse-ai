## The Problem

Your company pays $19-100/dev/month for AI coding tools. With 100 developers, that is $24K-120K/year. The CFO asks: *"Is this worth it?"*

The paradox: AI-assisted developers merge PRs 2x faster. But 2-3 weeks later, you see more rework, more incidents. Traditional velocity metrics show growth while quality quietly drops. No tool honestly answers: **"AI = +$X or -$X for your team."**

DevPulse AI answers that question.

## Key Metrics

| Metric | What It Measures |
|--------|-----------------|
| **AI Usage Rate** | % of PRs with AI markers (Co-Authored-By, commit patterns, config files) |
| **Cycle Time** | Hours from PR open to merge, split by AI vs non-AI |
| **Rework Rate** | % of PRs requiring fix commits within 14 days |
| **Bug Rate** | Bug issues per 100 PRs, AI-assisted vs manual |
| **Code Churn** | Lines changed in the same file within 14 days |
| **Review Load** | Average review comments per PR |
| **Net Productivity Score** | (speed gain - quality cost), normalized to a single number |

## Quick Start

### Option 1: Demo Mode (30 seconds)

```bash
git clone https://github.com/TimurRakhmatullin86/devpulse-ai.git
cd devpulse-ai
docker compose up -d db
npm install
npm run db:seed
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the dashboard with realistic sample data.

### Option 2: Docker (full stack)

```bash
git clone https://github.com/TimurRakhmatullin86/devpulse-ai.git
cd devpulse-ai
cp .env.example .env
docker compose up
```

2. Import into [Vercel](https://vercel.com/new)

## How AI Detection Works

DevPulse AI uses a layered detection system to identify AI-assisted pull requests. Each detection level adds confidence:

| Level | Signal | Confidence | Example |
|:-----:|--------|:----------:|---------|
| **L1** | `Co-Authored-By` trailer | High | `Co-Authored-By: copilot[bot]`, `Claude Sonnet` |
| **L2** | Commit message patterns | High | `"Generated by Cursor"`, `[ai]` prefix |
| **L3** | PR body / config markers | Medium | `"Generated with Claude Code"`, `.cursor/` dir |
| **L4** | Behavioral heuristic | Low | 500+ line PR authored in <30 minutes |

**Honest note on limitations:**
- L4 (behavioral) detection can produce false positives and is marked *experimental*.
- If developers disable `Co-Authored-By` trailers, L1 detection is unavailable.
- DevPulse AI reports what it can detect, not the ground truth. When in doubt, it flags PRs as "possibly AI-assisted" rather than asserting.

## Dashboard Pages

1. **Executive Summary** -- one number: "AI = +X% or -X% for your team"
2. **Speed vs Quality** -- cycle time and rework rate, AI vs non-AI side-by-side
3. **Per-Developer** -- who benefits most, who needs support (scatter plot + table)
4. **Per-Repository** -- same breakdown by repo
5. **Trends** -- weekly charts: adoption, speed, quality, ROI over time
6. **ROI Calculator** -- input license costs + salaries, get dollar ROI
7. **Settings** -- connected repos, detection config, webhook endpoint

## API Reference

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/summary?period=30d` | Executive summary metrics |
| `GET` | `/api/metrics?period=90d` | Weekly trend data |
| `GET` | `/api/developers?period=30d` | Per-developer breakdown |
| `GET` | `/api/repos?period=30d` | Per-repository breakdown |
| `GET` | `/api/prs?ai=true&limit=50` | PR list with AI/manual filter |
| `POST` | `/api/webhooks/github` | GitHub App webhook endpoint |

## Environment Variables

| Variable | Required | Description |
|----------|:--------:|-------------|
| `DATABASE_URL` | Yes | PostgreSQL connection string |
| `NEXTAUTH_URL` | Yes | App URL (`http://localhost:3000`) |
| `NEXTAUTH_SECRET` | Yes | Random secret for session encryption |
| `GITHUB_CLIENT_ID` | Yes | GitHub OAuth App client ID |
| `GITHUB_CLIENT_SECRET` | Yes | GitHub OAuth App client secret |
| `GITHUB_APP_ID` | Webhooks | GitHub App ID |
| `GITHUB_APP_PRIVATE_KEY` | Webhooks | GitHub App private key (PEM) |
| `GITHUB_WEBHOOK_SECRET` | Webhooks | Webhook signature verification secret |
